| 工作流 | 所缺证据 |

| 真实客户端生命周期与记忆消费 | 在已登录目标客户端的后续会话实际使用正确记忆；无账号连接不替代语义消费 |
| 真实模型质量、用量与费用 | 独立实测请求/回答/供应商用量、准确适用费率和统一比较条件；本模块只完成计算步骤 |

剩余消息数。以实际证据闭合报告进度；不因内部计算模块通过就扣除尚未做的外部
验收。Issue40仍未知，不把任何费用/配置/握手测试解释成其根因已经修复。
