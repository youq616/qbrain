## 获取源码而不改用户工作区

再创建独立的 detached worktree。不要切换、重置、清理或推送原工作区。
无需安装 MSVC/SDK/CMake；这是源码审核，不要求假冒本机原生编译验收。

```powershell
git fetch origin cccdacb61e63c29f8b9eaba1c38fbeed3e23e54b
# 审核父代理须为以下路径选择本次全新、仓库外的唯一临时目录。
```

两个结果必须对应本文候选提交和源树；下载或 Git 失败时保留错误，不绕过凭据、
不使用旧分支替代。本说明可能由后续纯文档提交提供，审核对象仍是上面的固定代码。
比较整个阶段差异，不只看最后一个启动锁补丁。
