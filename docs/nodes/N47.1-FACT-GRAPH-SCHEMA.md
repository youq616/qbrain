# N47.1 Fact Graph Schema

## Goal

Introduce a fact layer between raw evidence and long-term memory. Existing memory records remain unchanged; facts reference evidence instead of replacing it.

## Core entities

### fact

- `id`
- `subject`
- `predicate`
- `object`
- `confidence`
- `status`
- `created_at`
- `updated_at`

Status values:

- ACTIVE
- SUPERSEDED
- CONFLICT
- REJECTED

### fact_evidence

Links a fact to the original evidence.

Fields:

- `fact_id`
- `memory_id`
- `message_id`
- `source_hash`
- `extraction_method`

A fact without evidence cannot become trusted long-term memory.

### fact_relation

Stores graph relationships.

Examples:

- replaced_by
- contradicts
- confirms
- derived_from

## Design rules

1. Facts never overwrite previous facts.
2. New information creates a new version or conflict edge.
3. Evidence remains the source of truth.
4. Confidence is metadata, not permission to delete history.
5. Existing SQLite storage remains compatible; migration is additive only.
