# N47H plan review

Reviewer: ChatGPT, separate engineering self-review under owner authorization;
not a third party or an independent subagent. Verdict: PASS for implementation.
Runtime/outcome acceptance is still pending.

The missing step is read-only discovery, not another write mechanism. Reusing
N47G for selected application avoids automatic age-driven mutation. Advisory
creation age must not become truth, usage or confirmation confidence. Unknown
or future support timestamps cannot drive archive suggestions. Restore eligibility
still requires active, supported assertions; discovery cannot revive forgotten data.

Seek paging must not hide a row interrupted by output or work budgets. Advance
only after successful eligibility evaluation and either exclusion or inclusion.
Empty+continuation is incomplete; unchanged continuation must be explicitly
reported as no progress. Key cursors are untrusted filters, never scope tokens.
One-call snapshots do not imply stable state across calls; document changed or
new earlier IDs and require apply to revalidate. Shared evidence and SQL/output
bounds remain separate claims. Do not use OFFSET or silently skip a large candidate.

Metadata output avoids copying full user quotes to maintenance screens but still
requires source permissions. Old lifecycle output must remain equivalent if age
logic is extracted. Strict route-specific fields prevent a read payload from
being interpreted as a write. No migration, installer/provider change or paid model.

No P0/P1 design blocker identified in this scoped design. Required implementation
gates are pagination completeness on static data, timestamp and live-support
correctness, no read writes, no unauthorized mutation, bounded output/work,
native regression and separate outcome evidence. The design PASS is not a stage
completion verdict and cannot substitute for executing those tests.
